Phase 1: Lexical Analysis

The lexer scans source code and converts it into a stream of tokens. Each token has a type and a value. Whitespace, comments and structure are discarded here.

Phase 2: Syntax Analysis (AST)

The parser processes the token stream and builds an Abstract Syntax Tree (AST). Each node represents a language construct. The tree shows the hierarchical structure of the program.

🌳
Click Compile to build the AST

Phase 3: Symbol Table

The symbol table records all identifiers (variables, functions) along with their types, scopes, and other attributes. It is the compiler's "dictionary" for the program.

📋
Click Compile to build the symbol table

Phase 4: Semantic Analysis

Semantic analysis checks that the program is meaningful. This includes type checking, variable declaration checks, and function call validation.

🔬
Click Compile to run semantic analysis

Phase 5: Intermediate Representation (IR / TAC)

The compiler generates Three-Address Code (TAC) and an AST-based IR. TAC breaks complex expressions into simple instructions, each with at most three operands.
